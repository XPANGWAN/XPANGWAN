## About

I'm **XPANGWAN**, an independent developer focused on Android applications and practical digital products. I enjoy turning ideas into working features, improving performance, and refining the details that make an app easier to use.

My main project is **[MARCO RX6](https://github.com/XPANGWAN/Marco-RX6)** — an Android gaming-library app built to help people explore, organize, and manage their game collections.

## Featured Project

### [MARCO RX6](https://github.com/XPANGWAN/Marco-RX6)

- Discover and organize a multi-platform game library.
- Browse game artwork, information, and related links.
- Manage downloads with pause, resume, and cancel support.
- Sign in with Google or email, or use guest access.
- Integrate with Google Drive and Blogger.
- Customize the interface and use Arabic, English, French, or Spanish.

**Latest release:** [MARCO RX6 V8.32](https://github.com/XPANGWAN/Marco-RX6/releases/tag/V8.32)

## نبذة عني

أنا **XPANGWAN**، مطوّر مستقل أركز على تطبيقات Android وبناء منتجات رقمية عملية. أهتم بتحويل الأفكار إلى ميزات حقيقية، وتحسين الأداء، والاهتمام بالتفاصيل التي تجعل استخدام التطبيق أسهل.

مشروعي الرئيسي هو **[MARCO RX6](https://github.com/XPANGWAN/Marco-RX6)**، تطبيق مكتبة ألعاب لأندرويد يساعد المستخدمين على استكشاف ألعابهم وتنظيمها وإدارة مجموعاتهم.

## المشروع الرئيسي — MARCO RX6

- استكشاف وتنظيم مكتبة ألعاب متعددة المنصات.
- عرض أغلفة الألعاب ومعلوماتها وروابطها.
- إدارة التنزيلات مع الإيقاف المؤقت والاستئناف والإلغاء.
- تسجيل الدخول عبر Google أو البريد الإلكتروني، مع إمكانية الاستخدام كزائر.

- تخصيص الواجهة ودعم العربية والإنجليزية والفرنسية والإسبانية.
