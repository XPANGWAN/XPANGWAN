## About Me

I'm **XPANGWAN**, an independent developer interested in Android development and building useful digital experiences.

My main project is **[MARCO RX6](https://github.com/XPANGWAN/Marco-RX6)**, an Android gaming library that helps users organize, discover, and manage their game collections.

## Featured Project

### [MARCO RX6](https://github.com/XPANGWAN/Marco-RX6)

- Organize and explore a personal gaming library.
- Browse game covers and detailed information.
- Manage downloads with pause and resume controls.
- Google sign-in, email authentication, and guest access.
- Google Drive and Blogger integration.
- Customizable interface with multilingual support.
