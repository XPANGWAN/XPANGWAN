## ABOUT

I'm **XPANGWAN**, an independent developer focused on Android applications and practical digital products. I enjoy building features end-to-end, improving reliability, and shaping clear user experiences.

My main project is **MARCO RX6**, an Android game-library application built around game discovery, library management, downloads, and connected services.

## نبذة عني

أنا **XPANGWAN**، مطوّر مستقل أركز على تطبيقات Android والمنتجات الرقمية العملية. أحب بناء الميزات من الفكرة إلى التنفيذ، وتحسين الاعتمادية، والاهتمام بتجربة المستخدم.

مشروعي الرئيسي هو **MARCO RX6**، تطبيق أندرويد لمكتبة الألعاب يجمع بين استكشاف الألعاب وتنظيم المكتبة وإدارة التنزيلات والخدمات المتصلة.

## المشروع الرئيسي — MARCO RX6

- استكشاف مكتبة الألعاب والبحث والتصفية والتنظيم.
- إدارة التنزيلات مع الإيقاف المؤقت والاستئناف والإلغاء.
- تسجيل الدخول عبر Google أو البريد الإلكتروني، مع إمكانية الاستخدام كزائر.
- التكامل مع Google Drive وBlogger.
- واجهة قابلة للتخصيص ودعم العربية والإنجليزية والفرنسية والإسبانية.
